STEP 0 Claude Codeをまだ入れていない方へ（すでにお持ちの方は読み飛ばしてOK） ▾

Claude Codeは、Anthropic公式が配っているインストールコマンドで入れられます。お使いのOSに合わせて、どちらか1行をターミナルに貼り付けてください。インストール後、初めて「claude」と打って起動したときにブラウザが開き、ログインを求められます。案内に沿って進めばOKです。

Mac・Windowsどちらも対応無料でインストールできる初回起動時はブラウザでログイン使うにはPro以上のプラン登録が必要
Macの場合（ターミナル）▾ 
curl -fsSL https://claude.ai/install.sh | bash
Windowsの場合（PowerShell）▾ 
irm https://claude.ai/install.ps1 | iex

STEP 1 ／ Claude Code
新しいチャットで、サイト全体を生成するプロンプトを送る

空のフォルダでClaude Codeを起動し、このプロンプトをそのまま送信します。技術構成・演出内容・デザインルールまで全部指定済みなので、あとはそのまま実装が進みます。長いプロンプトですが、省略せず全文貼ってください。

サイト生成プロンプト▾ 
高級プロダクトのプロモーションWebサイトを制作してください。

Appleなどの世界的なプロダクトブランドに見られる、
ミニマルで没入感のあるスクロール型の商品紹介ページを参考にします。

ただしAppleのWebサイト、商品名、画像、ロゴ、文章、デザインをコピーせず、
完全オリジナルのサイトとして制作してください。

今回の商品名は

「AURA ONE」

架空のプレミアムデスクスピーカーです。

まず実装前に構成を設計してください。

技術構成は以下を使用してください。

- Vite
- Vanilla JavaScript
- Three.js
- GSAP
- GSAP ScrollTrigger

必要なnpmパッケージは自分でインストールしてください。

Three.jsでは商品を3Dで表現します。

外部3Dモデルが存在しない場合は、
Three.jsのGeometryを組み合わせて、

・アルミニウム製ボディ
・丸みのある縦型デザイン
・前面スピーカーグリル
・金属素材
・黒とダークグレー
・エッジ部分に柔らかな反射

を持つオリジナルのプレミアムスピーカーを作成してください。

Webサイト全体は以下の構成にしてください。

SECTION 1
Hero

黒い背景。

画面中央にAURA ONE。

大きく

「Sound.
Redefined.」

というコピーを表示。

スクロールを開始するとコピーがゆっくり消え、
商品が少しずつ拡大する。


SECTION 2
Design

商品を画面中央に固定。

スクロールに合わせて商品をY軸方向にゆっくり回転。

左側から

「Machined from a single form.」

というテキストを表示。

商品には柔らかいリムライトを当て、
金属表面に高級感のある反射を作る。


SECTION 3
Sound

背景を黒から非常に濃いブルーへ徐々に変更。

商品を少し左へ移動。

右側に

「360° Spatial Sound」

を表示。

商品周辺に非常に控えめな波紋または粒子表現を追加。


SECTION 4
Detail

カメラを商品の表面へ接近させる。

スピーカーグリルや金属表面の質感をクローズアップ。

「Every detail.
Precisely engineered.」

を表示。


SECTION 5
Final

商品を再び中央へ戻す。

背景を完全な黒へ。

「AURA ONE」

「Experience sound differently.」

ボタン

「Discover」

を表示。


スクロール演出にはGSAP ScrollTriggerを使用してください。

特に以下を使用してください。

- scrub
- pin
- timeline

スクロール量とアニメーションを滑らかに同期してください。

スクロール位置によって、

・商品位置
・商品回転
・商品スケール
・カメラ位置
・ライト
・背景色
・テキストopacity
・テキストposition

を変化させてください。

ユーザーがスクロールを止めた瞬間に
アニメーションが不自然に止まるのではなく、
少し追従する高級感のある動きにしてください。

ただしスクロールそのものをJavaScriptで過剰に変更せず、
操作性を損なわないようにしてください。


デザインルール

・黒を基調
・余白を大胆に取る
・1画面につき伝えるメッセージは1つ
・文字数を極端に少なくする
・巨大なタイポグラフィ
・商品を主役にする
・不要なカードUIを使用しない
・不要な枠線を使用しない
・不要なグラデーションを使用しない
・安っぽいネオン表現は禁止
・過剰な光彩は禁止
・高級プロダクト広告のようなライティング
・フォントはInterまたはシステムフォント
・レスポンシブ対応


Desktopだけではなく、

375px
430px
768px
1024px
1440px

を想定してください。

スマートフォンでは3D処理やアニメーションを軽量化してください。

prefers-reduced-motion: reduce
の場合は大きなスクロールアニメーションを抑制してください。

WebGLが利用できない場合でも、
最低限商品情報が読めるフォールバックを実装してください。

実装完了後、

npm run build

を実行しエラーがないことを確認してください。

最後に

・作成したファイル
・使用したライブラリ
・スクロールアニメーションの仕組み
・変更しやすいパラメータ

を説明してください。

まず設計を行い、
その後実装まで進めてください。

困ったときは

この一言で伝えればOK

Q商品の動きが忙しい
商品の動きが少し忙しいです。現在の回転速度を約50%まで落としてください。スクロール操作に対して即座に追従するのではなく、少し遅れて滑らかに追従する、重量感のある動きに変更してください。
Qスクロールがカクつく
各Section間の切り替えを現在より20〜30%長くしてください。scrubを使用し、スクロール位置と自然に同期させてください。
Qテキストが安っぽい
テキストアニメーションを、opacityだけでなくtranslateY 30px→0pxも組み合わせてください。派手なバウンスや回転は禁止です。商品の動きより0.2〜0.4秒程度遅れて現れるようにしてください。
Q背景が単調
黒をベースに維持しながら、商品周辺だけに非常に弱い環境光を追加してください。派手なグラデーション・ネオン・強いブルーは追加しないでください。
Qスマホ表示が崩れる
375px／390px／430pxを重点的に確認し、商品を少し小さくする・過剰な3D回転を減らす・pin区間を短くする・横スクロールを完全になくすよう調整してください。
